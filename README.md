# PhisDetect

An automated phishing detection system designed to protect users from cyber threats.

## 📌 About The Project

PhisDetect is a web-based application that leverages machine learning to analyze and detect phishing URLs. By utilizing a **Random Forest** classification algorithm, the system extracts lexical and structural features from inputted links to accurately determine malicious intent, providing an accessible and user-friendly platform for web security.

## 🚀 Features

* **User-Friendly Web Dashboard:** An intuitive interface to input URLs and view detailed analysis results.
* **Machine Learning Powered:** Uses a trained Random Forest model for high-accuracy classification.
* **Instant Verification:** Quickly analyzes structural and lexical features to return the safety status of the link.
